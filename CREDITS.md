# Credits

TrifoolPercent is a native Ship of Harkinian rebuild of the Triforce% ending.
It stands on the work of several teams:

## This repository

- **isaac** ([@Bubbagum88](https://github.com/Bubbagum88)) — project lead, design and in-game testing.
- **Claude** (Anthropic, Opus) — generated code, scenes, build scripts and docs, as co-author on each commit
  (`Co-Authored-By:` trailer).

## Upstream work used by this project

- The **Triforce% team** (Sauraen and contributors) wrote the original scenes, actors, cutscene and text that
  TrifoolPercent ports. Their license requires that any project using their content directly credit the Triforce%
  contributors in the in-game staff roll; a release of TrifoolPercent has to carry that.
- **Ship of Harkinian** / **HarbourMasters** — the engine this mod runs in, plus the Fast64 fork and the Torch
  asset converter used to build the scene and the models.
- **zeldaret/oot** — the OoT decompilation TrifoolPercent's C actors are shaped around.

Pull requests are welcome. By submitting one, you agree to be credited here under your preferred name or handle.
