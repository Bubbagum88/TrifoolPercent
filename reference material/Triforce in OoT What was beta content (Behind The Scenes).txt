Yes, we put the Triforce into OoT using nothing but button presses. :) Here's what was beta content vs newly created and more behind the scenes fun. Questions? Join   / discord  

Triforce% OoT ACE Showcase was presented by Sauraen, Savestate, and dwangoAC with the help of TASBot under the title Ocarina of Time Beta Showcase during the SGDQ 2022 TAS block after helping raise more than $228k for Doctors Without Borders. Triforce% was performed using an original, unmodified US 1.0 release cartridge of The Legend of Zelda: Ocarina of Time on a real, original N64 (the Nintendo 64 had a passive RGB mod for a clean video signal that did not affect gameplay in any way). Everything in this run was done live in front of an audience using only button presses on controllers, ultimately achieving ACE (Arbitrary Code Execution) using Stale Reference Manipulation (SRM, the OoT community name for this Use-After-Free exploit).

In this second video in the series from Games Done Quick's Hotfix show That's Never Happened Before hosted by Kungfufruitcup, Sauraen and dwangoAC break down each bit of Triforce% content and explain the entire run from start to finish with behind the scenes details on what aspects were beta content and what the team created based on inspiration from Nintendo commercials and advertising material as well as fan rumors.
